# Heroic Content Plan

## Priority 1: First Playable Loop

Create only enough content to prove the combat loop:

- 1 player
- 1 enemy type
- 1 projectile attack
- 1 movement skill
- 1 upgrade draft

## Priority 2: First School Assets

### Arcane

Create these first because Arcane is the clean baseline school.

- Magic Missile
- Arcane Blast
- Warp Pulse
- Spell Echo
- Arcane Orbit

Arcane should emphasize:

- instant casts
- repeated value
- long range
- low base damage

### Fire

Fire should be the first contrast school after Arcane.

- Fireball
- Flame Wave
- Ember Rain
- Ignition
- Cinder Wall

Fire should emphasize:

- very high damage
- burn
- area denial
- standard cast times

## Priority 3: Movement Pool

Author the core movement skills next because they are part of the same upgrade economy.

- Blink
- Teleport
- Invisibility
- Stoneskin
- Lunge
- Whirlwind
- Tunnel

## Priority 4: Remaining Schools

After Arcane and Fire, author the rest of the schools in this order:

1. Cold
2. Lightning
3. Earth
4. Mind
5. Blood
6. Poison

## Priority 5: Databases

Fill these databases once the first assets exist:

- `SchoolDatabase`
- `SkillDatabase`
- `MovementDatabase`

## Recommendation

Do not author all content at once.

Start with:

- Arcane school assets
- Fire school assets
- 2 or 3 movement skills
- one enemy wave

That gets the first playable loop out of the way fast.
