# Lightning Tree

## School Identity

- Base Damage: High
- Cast Style: Fast, 0.5 sec
- Area Shape: Linear + Chains
- Range: Long
- Cooldown: Standard
- Proc 1: Stun
- Proc 2: None

Lightning is the tempo school. It wins by reacting quickly, chaining damage through groups, and interrupting enemy momentum.

## 1. Chain Bolt
A fast bolt that leaps from target to target.

- Role: core chain damage
- Base: high damage, fast cast, long range

### Upgrade Path A: More Jumps
- Hits more enemies
- Better swarm value

### Upgrade Path B: Higher Damage
- Stronger per hit
- Better for elites

### Upgrade Path C: Longer Chain
- Leaps farther between targets
- Better battlefield reach

## 2. Static Field
A charged zone that punishes enemies for staying in place.

- Role: area control and stun setup
- Base: moderate damage, standard cooldown, long range

### Upgrade Path A: Bigger Field
- Larger zone
- Better coverage

### Upgrade Path B: Faster Ticks
- More frequent damage
- Better pressure

### Upgrade Path C: Stun Chance
- Briefly stuns enemies
- Stronger control value

## 3. Thunder Lance
A hard line strike that pierces through enemy formations.

- Role: line burst and priority target damage
- Base: high damage, fast cast, long range

### Upgrade Path A: Piercing Lance
- Passes through more enemies

### Upgrade Path B: Wider Lance
- Easier to hit packed groups

### Upgrade Path C: Critical Strike
- Higher burst against isolated targets

## 4. Spark Surge
Multiple quick sparks fire in a rapid burst.

- Role: burst tempo and light crowd pressure
- Base: high damage, fast cast, long range

### Upgrade Path A: More Sparks
- Extra bolts
- Better multi-target value

### Upgrade Path B: Faster Surge
- Shorter burst window
- Better reaction play

### Upgrade Path C: Target Spread
- Sparks arc to nearby enemies
- Better for clustered swarms

## 5. Storm Call
A delayed storm that lands repeated lightning strikes.

- Role: high-end area burst and stun pressure
- Base: high damage, standard cooldown, long range

### Upgrade Path A: More Strikes
- Additional hits
- Better swarm clear

### Upgrade Path B: Faster Strikes
- Shorter delay between hits
- Better immediate pressure

### Upgrade Path C: Violent Storm
- Stronger damage and stun potential
- Best capstone path

## Lightning Play Pattern

Lightning should feel like:

- fast reaction
- chaining damage through groups
- locking down openings
- interrupting dangerous enemy surges

## Lightning Design Rule

Lightning should be one of the best schools for:

- tempo
- burst
- chain pressure
- stun-based disruption
