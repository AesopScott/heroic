# Magic Schools Master

## Purpose

This is the single source of truth for the 8 magic schools in Heroic.

Each school has:

- a combat identity
- a value proposition
- a 5-skill tree
- 3 upgrade paths per skill

## Global School Roles

- Arcane: repeat casting, consistency, double-cast synergy
- Fire: burst damage, area denial, burn pressure
- Cold: control, slow, freeze, spacing
- Lightning: fast burst, chain damage, stun pressure
- Earth: heavy disruption, terrain control, long-range impact
- Mind: fear, confusion, decoys, behavior disruption
- Blood: sacrifice, bleed, drain, risky sustain
- Poison: contagious DoT, lingering zones, delayed collapse
