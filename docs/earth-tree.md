# Earth Tree

## School Identity

- Base Damage: Standard
- Cast Style: Slow, 2 sec
- Area Shape: Large Areas
- Range: Very Long
- Cooldown: Slow
- Proc 1: Knockdown
- Proc 2: Stun

Earth is the heavy control school. It wins by shaping the battlefield, forcing bad movement, and landing large disruptive hits from far away.

## 1. Stone Spike
Stone spikes erupt from the ground in a chosen area.

- Role: reliable terrain strike
- Base: standard damage, slow cast, very long range

### Upgrade Path A: More Spikes
- Extra spike hits
- Better swarm coverage

### Upgrade Path B: Larger Spikes
- Stronger damage per hit
- Better elite pressure

### Upgrade Path C: Ground Breaker
- Spikes also disturb terrain
- Stronger battlefield control

## 2. Boulder Toss
A heavy boulder crashes into enemies and can keep rolling through the fight.

- Role: impact damage and disruption
- Base: standard damage, slow cast, very long range

### Upgrade Path A: Bigger Boulder
- More damage
- Better burst

### Upgrade Path B: More Bounce
- Ricochets or continues into more targets
- Better multi-hit value

### Upgrade Path C: Crushing Boulder
- Stronger knockback and stun value
- Better control against swarms

## 3. Earth Wall
Walls of stone block movement and create choke points.

- Role: battlefield shaping
- Base: standard damage, slow cast, very long range

### Upgrade Path A: Longer Wall
- More coverage
- Better lane control

### Upgrade Path B: Taller Wall
- Blocks more movement paths
- Better denial

### Upgrade Path C: Harden Wall
- Wall lasts longer and resists damage
- Better sustain in long fights

## 4. Quake
The ground shakes in a wide area, punishing enemies around the target zone.

- Role: large-area disruption
- Base: standard damage, slow cast, very long range

### Upgrade Path A: Larger Quake
- Wider radius
- Better coverage

### Upgrade Path B: Stronger Quake
- More damage
- Better burst

### Upgrade Path C: Repeated Quake
- Multiple pulses over time
- Better area denial

## 5. Mud Trap
Thick mud slows enemies and drags them into bad positions.

- Role: slow field and movement control
- Base: standard damage, slow cast, very long range

### Upgrade Path A: Bigger Trap
- Larger slow zone
- Better catch radius

### Upgrade Path B: Stickier Mud
- Stronger slow
- Better control value

### Upgrade Path C: Heavy Mud
- Enemies in the mud take extra damage
- Better setup for combo schools

## Earth Play Pattern

Earth should feel like:

- slow but authoritative casting
- strong arena shaping
- punishing enemy movement
- setting up traps and choke points

## Earth Design Rule

Earth should be the strongest school for:

- terrain control
- large area disruption
- forcing enemies into bad routes
- slow, heavy battlefield dominance
