# Poison Tree

## School Identity

- Base Damage: High
- Cast Style: Standard DoTs
- Area Shape: Many
- Range: Standard
- Cooldown: Long
- Proc 1: Contagious
- Proc 2: Disabled

Poison is the attrition school. It wins by spreading damage over time, weakening groups, and collapsing enemy formations through infection.

## 1. Poison Dart
A quick strike that injects venom into a target.

- Role: core poison application
- Base: high damage, standard DoT cast, standard range

### Upgrade Path A: More Darts
- Extra shots
- Better coverage

### Upgrade Path B: Stronger Poison
- More damage over time

### Upgrade Path C: Spread Poison
- Poison jumps on hit
- Stronger crowd infection

## 2. Toxic Cloud
A lingering cloud of venom that chokes enemy space.

- Role: area denial and attrition
- Base: high damage, standard DoT cast, many-area coverage

### Upgrade Path A: Bigger Cloud
- Larger area
- Better coverage

### Upgrade Path B: Longer Cloud
- Cloud lasts longer

### Upgrade Path C: Heavier Cloud
- Stronger damage over time
- Better swarm collapse

## 3. Venom Trail
A trail of poison remains behind the caster or a moving effect.

- Role: path control and pursuit pressure
- Base: high damage, standard DoT cast, standard range

### Upgrade Path A: Longer Trail
- More coverage

### Upgrade Path B: Stronger Trail
- More damage

### Upgrade Path C: Sticky Trail
- Enemies are slowed in it
- Better chase control

## 4. Infection
Poison spreads from one enemy to nearby enemies, building pressure over time.

- Role: contagion and snowball damage
- Base: high damage, standard DoT cast, many-area coverage

### Upgrade Path A: Faster Spread
- Poison jumps more often

### Upgrade Path B: Stronger Infection
- Damage ramps harder

### Upgrade Path C: Collapse
- Infected enemies burst on death
- Better chain-clear value

## 5. Rot Bloom
A toxic burst blossoms outward and leaves decay behind.

- Role: burst into lingering area
- Base: high damage, standard DoT cast, many-area coverage

### Upgrade Path A: Bigger Bloom
- Larger explosion

### Upgrade Path B: More Bloom Damage
- Stronger burst

### Upgrade Path C: Lingering Rot
- Leaves a poisonous zone behind
- Best long-fight path

## Poison Play Pattern

Poison should feel like:

- setting enemies up for delayed collapse
- spreading damage through the wave
- creating toxic zones
- winning through inevitability

## Poison Design Rule

Poison should be the strongest school for:

- damage over time
- contagion
- battlefield contamination
- turning a crowd into a spreading problem
