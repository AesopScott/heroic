# Heroic Design Notes

## Summary

Heroic is a web-based single-player bullet heaven built around a living spellbook.

The player starts with a basic spell and levels into a custom build by choosing from:

- Attack abilities
- Defense abilities
- Systems
- Boosts
- Movement skills every other level

## Key Progression Rules

- Every level: one non-movement upgrade category
- Every other level: one movement choice as well
- Movement choices can add a new movement skill or boost an existing one
- Up to three movement skills may be equipped
- Movement skills map to keys 1, 2, and 3

## The 8 Schools

- Arcane
- Fire
- Cold
- Lightning
- Earth
- Mind
- Blood
- Poison

## Magic Identity Snapshot

- Arcane: repeat casting, double-cast, long-range consistency
- Fire: very high burst, burn, area denial
- Cold: control, slow, freeze
- Lightning: fast burst, chain damage, stun
- Earth: slow heavy hits, terrain pressure, knockdown
- Mind: instant cone disruption, fear, confusion
- Blood: standard cast, bleed and drain, sacrifice sustain
- Poison: high DoT pressure, contagious spread, disabled targets

## Movement Identity Snapshot

- Blink: short, offensive and defensive reposition
- Teleport: longer cooldown, pure mobility
- Invisibility: untargetability, enemy aggro break, optional decoy
- Stoneskin: slow movement, high offense and defense
- Lunge: ground-based aggressive burst movement
- Whirlwind: offensive movement through mobs
- Tunnel: underground untargetability with surfacing bonuses

## Arcane Example

Arcane is the first school to be detailed.

Example skill structure:

- Magic Missile
- Arcane Blast
- Warp Pulse
- Spell Echo
- Arcane Orbit

Each skill can have 3 upgrade paths.

## Movement Example

Movement is treated as a strategic build lane, not utility filler.

The current movement set is:

- Blink
- Teleport
- Invisibility
- Stoneskin
- Lunge
- Whirlwind
- Tunnel
