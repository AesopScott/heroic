# Blood Tree

## School Identity

- Base Damage: Standard
- Cast Style: Standard
- Area Shape: Ground Effects and single targets
- Range: Standard
- Cooldown: Standard
- Proc 1: Bleed
- Proc 2: Drain

Blood is the sacrifice school. It wins by trading health for power, draining enemies to stay alive, and applying relentless bleed pressure.

## 1. Blood Bolt
A focused strike that cuts enemies and feeds the caster.

- Role: reliable sustain damage
- Base: standard damage, standard cast, standard range

### Upgrade Path A: More Damage
- Stronger direct hit

### Upgrade Path B: Lifesteal
- Heal from hits
- Better sustain

### Upgrade Path C: Splash Drain
- Damages and drains nearby enemies
- Better into clusters

## 2. Sanguine Pact
A ritual that trades life for more power.

- Role: sacrifice engine
- Base: standard effect, standard cast, standard cooldown

### Upgrade Path A: More Power
- Bigger gain from sacrifice

### Upgrade Path B: More Healing
- Better recovery after sacrifice

### Upgrade Path C: Lower Cost
- Sacrifice costs less health
- Easier to use safely

## 3. Blood Nova
A burst of blood magic explodes outward in a dangerous ring.

- Role: burst and sustain
- Base: standard damage, standard cast, standard range

### Upgrade Path A: Bigger Nova
- Larger blast radius

### Upgrade Path B: Stronger Nova
- More damage

### Upgrade Path C: Healing Nova
- Damages enemies and heals the caster
- Stronger hybrid build option

## 4. Leech Bind
A binding drain effect links the caster to one or more enemies.

- Role: sustain lock and attrition
- Base: standard damage, standard cast, standard range

### Upgrade Path A: Longer Bind
- Lasts longer
- Better control and drain time

### Upgrade Path B: Stronger Drain
- More life stolen
- Better sustain

### Upgrade Path C: Multi-Bind
- Links multiple enemies together
- Stronger group pressure

## 5. Crimson Frenzy
A blood-fueled overdrive that turns risk into power.

- Role: aggressive self-buff
- Base: standard damage, standard cast, standard cooldown

### Upgrade Path A: Faster Attacks
- More attack speed

### Upgrade Path B: More Damage
- Stronger offensive output

### Upgrade Path C: Low Health Power
- Stronger when near death
- Best risk-reward path

## Blood Play Pattern

Blood should feel like:

- trading health for output
- healing by hurting enemies
- bleeding targets down over time
- getting stronger when the fight gets dangerous

## Blood Design Rule

Blood should be the strongest school for:

- sacrifice mechanics
- drain and lifesteal
- bleed pressure
- risky power spikes
