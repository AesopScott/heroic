# Mind Tree

## School Identity

- Base Damage: Standard
- Cast Style: Instant
- Area Shape: Cones
- Range: Short
- Cooldown: Short
- Proc 1: Fear
- Proc 2: Confuse

Mind is the disruption school. It wins by breaking enemy behavior, forcing bad movement, and turning enemy pressure into chaos.

## 1. Psychic Lance
A sharp mental strike that hits a single target or a narrow line.

- Role: precision disruption
- Base: standard damage, instant cast, short range

### Upgrade Path A: More Damage
- Stronger hit
- Better against elites

### Upgrade Path B: Longer Range
- Safer casting distance

### Upgrade Path C: Mind Pierce
- Ignores part of enemy defenses
- Stronger against tough targets

## 2. Fear Wave
A cone of mental pressure that drives enemies away.

- Role: crowd scatter and spacing
- Base: standard damage, instant cast, short range

### Upgrade Path A: Bigger Wave
- Wider cone
- Better crowd reach

### Upgrade Path B: Longer Fear
- Enemies flee for more time

### Upgrade Path C: Stronger Panic
- Enemies behave less predictably
- Better disruption value

## 3. Illusion Clone
A false copy distracts enemies and absorbs attention.

- Role: decoy and positioning support
- Base: standard damage, instant cast, short range

### Upgrade Path A: More Clones
- Extra decoys
- Better distraction coverage

### Upgrade Path B: Stronger Decoys
- Clones last longer
- Better aggro control

### Upgrade Path C: Clone Burst
- Clones punish nearby enemies when destroyed
- Better combo payoff

## 4. Confuse
Enemies struck begin misreading the battlefield and each other.

- Role: behavior disruption
- Base: standard damage, instant cast, short range

### Upgrade Path A: Wider Effect
- Affects more enemies

### Upgrade Path B: Longer Confusion
- Confusion lasts longer

### Upgrade Path C: Deeper Confusion
- Enemies turn on each other more often
- Stronger chaos build option

## 5. Mind Crush
A heavy psychic blow that punishes weakened enemies.

- Role: finisher and burst disruption
- Base: standard damage, instant cast, short range

### Upgrade Path A: More Damage
- Stronger burst

### Upgrade Path B: Area Crush
- Hits a wider zone

### Upgrade Path C: Execution Crush
- Deals more damage to weakened enemies
- Better cleanup tool

## Mind Play Pattern

Mind should feel like:

- close-range control
- fear-based spacing
- decoy and confusion tactics
- turning enemy waves into a mess

## Mind Design Rule

Mind should be the strongest school for:

- fear
- confusion
- decoys
- short-range battlefield disruption
