# Heroic Music Brief For Suno

## Drop-In Path

Export or rename the chosen track to:

`Assets/_Heroic/Resources/Audio/Music/HeroicDemoLoop.wav`

Unity loads this at runtime as:

`Audio/Music/HeroicDemoLoop`

MP3 or OGG can work too, but keep the base filename exactly `HeroicDemoLoop`.

## Direction

- Seamless instrumental loop for a two-minute bullet-heaven investor demo.
- Fantasy is "living spellbook under pressure," not generic heroic fanfare.
- Mood should feel arcane, elegant, dangerous, and kinetic.
- Tempo target: 120-135 BPM.
- Length target: 60-120 seconds, loopable.
- No vocals, no lyrics, no hard ending, no long ambient intro.
- Leave room for procedural spell and hit SFX.

## Suno Prompt

```text
seamless loop, instrumental, dark arcane fantasy synthwave orchestral hybrid, living spellbook, magical missiles, elegant tension, pulsing arpeggios, glass celesta, low taiko-like percussion, subtle choir pad texture without vocals, no lyrics, no lead vocal, game soundtrack loop, 128 BPM, clean mix, loopable ending
```

## Negative Direction

- Avoid vocals or intelligible chants.
- Avoid a huge cinematic ending.
- Avoid slow intros longer than four bars.
- Avoid wall-of-sound bass that hides spell effects.
- Avoid references to specific copyrighted composers, games, or soundtracks.

## Export Notes

- Prefer WAV for the first import.
- Normalize conservatively so the music does not overpower SFX.
- If possible, trim the start and end so the loop returns cleanly to bar one.
