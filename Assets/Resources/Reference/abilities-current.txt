# Abilities - Current Game

Date: 2026-07-12
Category: reference

## Summary

- This is the canonical ability design reference for Heroic.
- It includes every current named magic-school ability, movement skill, and standalone spell system.
- It also fills missing design fields for placeholder skills so the next pass can review, tune, implement, and test every skill one by one.
- Current Main source snapshot: commit `a807ce3` (`Add skill icon HUDs`) on 2026-07-12.
- Current code has 61 named magic-school ability entries: Arcane has 5; Fire, Cold, Lightning, Earth, Mind, Blood, and Poison each have 8.
- Target school count is 8 skills per element. Arcane reaches 8 with three added skills: Force Field, Time Warp, and Haste.
- Grid conversion: `1 small grid square = 3 x 3 world units`; `1 grid = 3 world units` for range/radius review.

## Canonical Fields

Every ability should be reviewed against these fields before implementation is considered complete.

| Field | Requirement |
|---|---|
| Skill name | Player-facing name |
| School / lane | Arcane, Fire, Cold, Lightning, Earth, Mind, Blood, Poison, Movement, or System |
| Ability type | Projectile, Area of Effect Caster, Area of Effect Enemy, Area of Effect Ground, Augmentation, Cone, Line, or Nearest Enemy |
| Acquisition | Starts enabled, draft unlock, movement draft, system draft, or design addition |
| Base cooldown | Seconds between automatic casts or activations |
| Range | World units; include radius/length/width where relevant; divide by 3 to review in grid squares |
| Damage / value | Base damage, tick damage, buff value, cost, or healing value |
| Duration | Persistent, instant, travel time, buff duration, field duration, or status duration |
| Targeting | Nearest enemy, target ground, caster-centered, facing direction, random area, or manual activation |
| Gameplay | What the skill does in play |
| Upgrades | Exactly three upgrade paths, each with five explicit tier values |
| Visualization | Exact readable in-game effect target |
| Implementation status | Implemented, partially implemented, or design populated / implementation pending |

## Ability Type Taxonomy

| Ability Type | Meaning |
|---|---|
| Projectile | A missile, shard, dart, boulder, orb, or other traveling object |
| Area of Effect Caster | Area originates from, follows, or surrounds the player |
| Area of Effect Enemy | Area is centered on or around enemies |
| Area of Effect Ground | Persistent or placed zone on the ground |
| Augmentation | Buff, aura, passive modifier, summon/support behavior, invulnerability, or self-state |
| Cone | Directional widening area projected from the caster |
| Line | Straight beam, wall, fracture, lance, or linear strike |
| Nearest Enemy | Automatically targets one or more nearby enemies without a projectile body |
